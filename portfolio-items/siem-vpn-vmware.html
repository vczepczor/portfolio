Detail Projektu

Security Operations Center Laboratory

Implementace monitorovací infrastruktury pro detekci kybernetických incidentů

Funkční SOC laboratorní prostředí

Březen 2026 Cybersecurity Školní projekt

Projekt se zaměřuje na vytvoření kompletního Security Operations Center (SOC) laboratorního prostředí s praktickou demonstrací detekčních schopností SIEM systému. Virtualizované prostředí simuluje reálnou firemní infrastrukturu s třívrstevnou síťovou architekturou a pokročilými bezpečnostními mechanismy.

Přehled Projektu

SOC Lab implementuje segmentovanou síťovou architekturu se třemi bezpečnostními zónami: external network (simulace internetu), DMZ s VPN gateway, a internal network s kritickými systémy. Celá infrastruktura běží na 4 virtuálních strojích s celkovou alokací 15GB RAM a využívá open-source bezpečnostní nástroje pro monitoring a detekci hrozeb v reálném čase.

Klíčové Vlastnosti

  • Centrální SIEM monitoring (Wazuh 4.9.2) s real-time alerting
  • Třívrstevná síťová segmentace s firewall enforcement
  • Šifrovaný VPN tunel (WireGuard) pro secure remote access
  • Automatická intrusion prevention (Fail2ban) s IP banning
  • File Integrity Monitoring kritických systémových souborů
  • Simulace 7 reálných kybernetických útoků s analýzou detekce

Technická Implementace

Infrastruktura využívá VMware Workstation pro virtualizaci 4 systémů: SIEM server (Ubuntu 22.04, 6GB RAM) s Wazuh all-in-one deployment, VPN Gateway (2GB RAM) s dual-homed konfigurací, Database server (4GB RAM) s PostgreSQL a Flask API, a Kali Linux (3GB RAM) pro penetration testing. Síťová izolace je zajištěna pomocí virtuálních sítí VMnet1 (external 192.168.1.0/24) a VMnet2 (internal 10.0.0.0/24) s přísnou firewall politikou na VPN gateway.

Výsledky Testování

Během attack simulation fáze bylo provedeno 7 různých attack scenarios: SSH brute force (detekováno + auto-mitigováno), port scanning (nedetekováno - limitace log-based SIEM), SQL injection (endpoint bezpečný), file integrity violations (detekováno během 5 minut), data exfiltration (úspěšný - chybějící API auth), a privilege escalation (detekováno, ale příliš pozdě). Celková detection rate: 43% plná detekce, 29% částečná detekce, 29% nedetekováno. False positive rate: 38% (vyžaduje tuning).

SIEM je nástroj pro detekci, ne prevenci. Úspěšný privilege escalation útok demonstruje fundamentální pravdu kybernetické bezpečnosti: žádný systém není 100% bezpečný. Cílem není zabránit všem útokům, ale minimalizovat attack surface, detekovat rychle, a reagovat efektivně.

Praktický Přínos

Projekt poskytuje hands-on zkušenosti s enterprise security technologiemi včetně SIEM deployment, network segmentation, VPN implementation, a incident response. Demonstruje realistické limity detekčních technologií a důležitost layered security approach. Prostředí může sloužit jako tréninkový lab pro security awareness, penetration testing cvičení, nebo jako proof-of-concept pro SMB security monitoring řešení.
