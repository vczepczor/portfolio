# Osobní webové portfolio 🚀

Tento repozitář obsahuje zdrojové kódy mého osobního webového portfolia a blogu. Web slouží jako online vizitka, kde prezentuji své IT projekty, zkušenosti a služby, na které se zaměřuji.

🌍 **Živá ukázka webu:** [vczepczor.github.io/vaclavczepczor](https://vczepczor.github.io/vaclavczepczor/)

## 🛠️ Použité technologie

Web je postaven jako statická stránka s využitím moderních front-end technologií bez použití složitého backendu (pro maximální rychlost a snadný hosting):

* **HTML5 & CSS3**
* **Bootstrap 5** - pro plně responzivní a moderní design
* **JavaScript (Vanilla)** - pro interaktivní prvky (psací efekt, filtrování portfolia, navigace)
* **GitHub Pages** - pro automatický deployment a hosting

## 📂 Co na webu najdete

* **O mně & Životopis:** Informace o mém studiu IT a cestě k technologiím.
* **Služby:** Přehled oblastí, kterým se věnuji (Správa Linuxu, Python automatizace, Kyberbezpečnost a sítě, Webový vývoj).
* **Portfolio:** Ukázky mých reálných projektů (např. *Smart Lock Door s Raspberry Pi a biometrií*, vlastní Linux servery, Python skripty).
* **Blog:** Moje technické zápisky, postřehy z vývoje a návody.
* **Kontakt:** Formulář a odkazy pro navázání spolupráce.
